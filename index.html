🛡️ CONTENT PROTECTION SETTINGS

Control content deterrence on the public Barangay website. The server-side watermark is the strongest protection layer — it embeds the watermark directly into the image file, so it persists even in screenshots.

Master switch — turns off all protection layers when disabled.

Prevents context menu on hero, gallery, and official photos.

Prevents users from dragging images to save them.

🖼️ Watermark Settings

Shows watermark on hero section and gallery images (CSS overlay + server-side embed on new uploads).

Use {barangay} or {year} for dynamic substitution.

Recommended: 25–40%

ℹ️ Known Limitations & What This Cannot Do
This is a deterrence system, not a lock.
✅ Right-click block — effective against casual users
✅ Drag prevention — effective
✅ CSS watermark overlay — visible in screenshots
✅ Server-side watermark (Pillow) — embedded in file itself, strongest layer
❌ Screenshot prevention — not possible in a browser
❌ Screen recording prevention — not possible
❌ Browser DevTools access — cannot prevent
❌ Browser extensions — cannot block
🩺 DATA INTEGRITY CHECK

Scans the database for duplicate IDs, orphaned references, invalid classifications/statuses, and missing timestamps.
